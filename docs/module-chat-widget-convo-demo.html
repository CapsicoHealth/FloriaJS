Conversation Visualizer - Complex Example

Multi-Agent Conversation with 3-Level Nesting (Coordinator → Medical → Cardiology + Billing → Insurance)

Complex Multi-Level Example

This demonstrates a realistic complex conversation with 3 levels of nesting and parallel agent calls

  • Depth: 3 (Coordinator → Medical Agent → Cardiology Specialist)
  • Total Agents: 5 (Coordinator, Medical, Cardiology, Billing, Insurance)
  • Total Events: 15+ (tool calls + agent calls)
  • Parallel Paths: Medical and Billing agents run in parallel
  • Best View: Sankey Flow (auto-selected for depth ≤ 3)

Visualization Controls:

  • Flow View (→): Sankey-style flow diagram showing data movement through agents and tools
  • Tree View (⊞): Collapsible hierarchical tree. Click nodes to expand/collapse branches
  • Tree Controls Panel: In Tree view, use the control panel (top right) to:
    • Node Spacing: Choose Compact (tight), Normal (default), or Spread (spacious)
    • Expand All: Open all collapsed nodes at once
    • Collapse All: Close all nodes to see just the top level
    • Panel Toggle: Click the header to collapse/expand the control panel

Visual Encoding:

  • Color: Heat map based on token usage (🟢 Green = low, 🟡 Yellow = medium, 🔴 Red = high)
  • Size/Thickness: Proportional to total tokens (input + output)
  • Hover: Shows detailed metadata (tokens, cost, model, provider)

Usage Example:

  • Import: import { createConversationVisualizer } from './module-chat-widget-convo.js';
  • Initialize: const viz = createConversationVisualizer('containerId', conversationData);
  • The visualizer automatically selects the best default view based on conversation depth
  • Users can toggle between views using the control buttons

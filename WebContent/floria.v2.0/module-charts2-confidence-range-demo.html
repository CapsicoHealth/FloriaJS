Line charts with confidence ranges

Each line uses its own lower and upper values to draw a light band. The default band is tinted from that series' line color; both series below use that default.

Data shape and optional fill override

const point = {
        x: 1, y: 42, range: [38, 47]
};

chart.addLine(data, { labelFull: "Treatment" },
  { borderColor: "#187f73", borderWidth: 2 });

// Optional final argument to addLine:
chart.addLine(data, { labelFull: "Treatment" },
  { borderColor: "#187f73", borderWidth: 2 },
  undefined, undefined,
  { backgroundColor: "rgba(24, 127, 115, 0.18)" });

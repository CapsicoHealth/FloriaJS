Box-and-whisker charts

Compare the response distributions for two cohorts across five visits. Boxes use the 25th and 75th percentiles; points beyond the whiskers are shown as outliers.

Data shape

chart.addBoxPlot([
  { x: "Visit 1", values: [12, 15, 18, 21, 24] },
  { x: "Visit 2", values: [14, 17, 20, 22, 26] }
], { labelFull: "Cohort A" }, visualSpecs);
